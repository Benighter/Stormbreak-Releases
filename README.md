# Stormbreak downloads

An original action game by Bennet. Ten chapters. Three interceptors. One storm.

This repository contains signed Android downloads, checksums, update metadata and release notes. Game implementation, editable assets and signing material are maintained separately in private storage.

Install a signed release APK on Android. Future versions can be checked from Settings > Updates in the game. Android asks you to confirm installation. Your existing Stormbreak save remains in place when updating with the same package and signing key.
